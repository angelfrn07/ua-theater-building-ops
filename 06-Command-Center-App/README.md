# Power Church Commander

The volunteer/project command center for getting the building up and running — a real app,
not a document. Live at:

**https://power-church-commander.myroyal-estates.workers.dev**

## What it does

- Invite-link sign-in with roles: Owner/Operator (admin), Pastor, Captain (team leader),
  Volunteer
- Jobs with photo-proof verification, organized by room
- A CAD-derived map of the building with pins on all 14 auditoriums so a job says exactly
  where to go
- Every job answers: who do you report to, what should your photo show, what to do if you're
  stuck
- A 6:30am daily sweep that flags anything stalled, not moved, or waiting on a team leader

## How to get in

There's no public sign-up — Angel issues a personal invite link per person, tied to the right
role. If you don't have yours yet, ask Angel directly.

## Where the code lives

The app's source code is a separate, private repository — kept apart from this one on
purpose, the same way a business keeps its software and its filing cabinet in different
places. This folder is the front door; the engine lives elsewhere.
